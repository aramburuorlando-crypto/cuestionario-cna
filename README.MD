# 🏛️ Cuestionario Interactivo: Constitución Nacional Argentina

¡Bienvenido/a! Este es un **recurso digital interactivo** diseñado con el objetivo de acercar a los ciudadanos argentinos al conocimiento de sus **derechos, deberes y garantías constitucionales** de una manera lúdica, accesible y moderna.

## 🔗 Demo en Vivo
Puedes acceder y probar la aplicación directamente desde tu navegador aquí:
👉 **[Hacé clic aquí para realizar el cuestionario](https://TU_USUARIO.github.io/TU_REPOSITORIO/)** *(Reemplazá con tu enlace de GitHub Pages)*

---

## 🎯 Características Principales

* **Aprendizaje Activo:** Preguntas dinámicas basadas firmemente en el texto oficial de la Constitución Nacional.
* **Secciones Temáticas:** Evaluación interactiva sobre Derechos Políticos, Nuevos Derechos y Garantías (como el Amparo y Hábeas Corpus).
* **Feedback Inmediato:** Explicaciones sencillas al responder para fijar conceptos cívicos clave.
* **Diseño Responsivo:** Adaptado completamente para resoluciones de celulares, tablets y computadoras.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando tecnologías web estándar (sin frameworks complejos) para garantizar un rendimiento óptimo y una carga ultrarrápida:

* 🌐 **HTML5:** Estructura semántica de los formularios y contenedores del quiz.
* 🎨 **CSS3:** Estilos personalizados, transiciones suaves y diseño adaptativo (*Media Queries*).
* ⚡ **JavaScript (Vanilla):** Lógica del cuestionario, validación de respuestas correctas, cálculo del puntaje final y control del estado del juego.
